I am creating a Kanban-style task tracker and plan to add a search and combined filter bar by extending the GET /tasks endpoint with in-process filtering, using simple substring matching for title and description and supporting filters for status, priority, and assignee in a single request flow. I could have considered a database-driven approach with server-side query parameters and a dedicated search service, but I rejected those as more complex and unnecessary for this scope; I also chose not to introduce any third-party libraries or a separate indexing layer, since the app’s current needs are lightweight and the simpler implementation is sufficient.
