I used Claude.ai mainly for product-facing work: drafting user stories and reviewing the ADR. It was useful for turning a rough feature brief into structured stories with clear acceptance criteria, and it helped me think through scope boundaries before implementation. I used Copilot Chat for the implementation work in app/main.py, app/storage.py, and app/models.py, where it was especially helpful for making targeted code changes, suggesting route and storage updates, and helping me keep the backend aligned with the tests. One moment AI helped a lot was when I used it to think through regressions during verification. The break-test examples in docs/verification.md showed how quickly a small change could break expected behavior, and AI helped me reason about what to test and how to restore correctness. One moment it slowed me down was when it suggested overly broad or abstract changes for implementing backend code changes. Those ideas were acceptable, but they added scope beyond the module and required extra review to narrow them back down. My review changed the result most clearly in the user stories in docs/user-stories.md. I had to push back on AI assumptions such as adding extra filters or implying unsupported features, and that kept the stories aligned with the actual Module 1 scope. Overall, AI accelerated the workflow, but human review was essential to keep the output practical, testable, and constrained.
